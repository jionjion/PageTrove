# 拾页

> 拾取互联网有价值的碎片

**拾页**是一款浏览器侧边栏扩展，让你在浏览网页时随时召唤 AI 助手——对当前页面提问、一键生成摘要与标签、将有价值的网页整理收藏到本地。

## 核心功能

### AI 网页对话

打开侧边栏即可针对当前页面向 AI 提问。扩展自动提取页面正文作为上下文，也支持手动选取页面中的特定元素，让 AI 回答更精准。对话支持 Markdown 渲染和流式输出。

### 智能收藏

点击「整理」，AI 自动为当前网页生成摘要和标签（最多 5 个），你可以在确认前自由编辑，还能附上自己的收藏理由。告别杂乱的书签栏，让每一条收藏都有意义。

### 收藏管理

所有收藏支持关键词搜索（覆盖标题、标签、摘要、备注、选中文字和正文全文）和标签筛选，正文命中时会显示上下文片段。可随时编辑备注与标签、跳回原网页，也可以针对已收藏的内容发起新对话，深入了解。

### 右键引用提问

在网页中选中文字后，右键选择「向拾页提问」即可打开侧边栏，选中内容以引用卡片形式出现在输入区上方，输入问题后手动发送。不会自动发送任何请求。

### 多来源探究

- **多标签页探究**：在侧边栏点击「探究」，勾选当前窗口中 2–5 个网页，确认后统一读取正文并发起问答。
- **收藏探究**：在收藏列表进入选择模式，勾选 2–5 条收藏发起限定范围问答。

多来源回答使用 `[S1]`、`[S2]` 标注结论来源，可折叠查看来源列表。

### Obsidian 导出

收藏可导出为 Obsidian 兼容的 Markdown（含 YAML Frontmatter）：单条导出 `.md`，多条或全部导出为带索引的 `.zip`。导出完全在浏览器本地生成，不包含 API Key、MCP 配置和聊天历史。

### 历史对话

所有 AI 对话自动保存在本地，可随时回看或继续未完成的讨论。

### 多模型与截图问答

内置 DeepSeek、Kimi（月之暗面）、智谱 GLM、通义千问、OpenAI 五家供应商预设，也支持任意 OpenAI 兼容接口的自定义配置。模型能力按“供应商 + 模型”分别设置；支持图片输入的模型可以对手动框选的页面截图或含视觉内容的页面元素进行问答。截图仅用于当前请求，聊天历史只保留 `[截图]` 占位。

### MCP 工具

可连接远程 Streamable HTTP 或旧版 SSE MCP Server。设置页支持测试连接、查看工具列表，并分别启用或停用服务和工具；支持工具调用的模型可以在对话中自动调用已启用工具。MCP Token 和自定义请求头只保存在本机，不包含在收藏导出中。

## 快速开始

1. 安装扩展后，点击工具栏图标打开侧边栏
2. 进入设置页，选择 AI 供应商（Base URL 与模型自动填充）
3. 填入对应供应商的 API Key
4. 开始对话或收藏网页

## 隐私与安全

- **零后端**：无任何服务器，所有数据仅存储在浏览器本地——收藏和聊天保存在本地 IndexedDB，设置保存在 `browser.storage.local`
- **密钥本地化**：API Key 由你自行填写，仅保存在 `browser.storage.local`，不会上传到任何第三方
- **直连 AI**：请求由浏览器直接发送至你选择的 AI 供应商，中间无代理

## 兼容性

- Chrome（MV3 Side Panel）
- Microsoft Edge

## 开发

```bash
pnpm install        # 安装依赖
pnpm dev            # Chrome 开发模式
pnpm dev:edge       # Edge 开发模式
pnpm compile        # 类型检查
pnpm build          # 生产构建（.output/chrome-mv3）
pnpm zip            # 打包发布 zip
```

技术栈：[WXT](https://wxt.dev/) + React + TypeScript + Ant Design
